# Portfolio — Htet Aung Lin

Built with [Hugo](https://gohugo.io) and the [PaperMod](https://github.com/adityatelange/hugo-PaperMod) theme.
Deployed automatically to GitHub Pages by `.github/workflows/hugo.yml` on every push to `main`.

## Edit content
- Home page intro and links: `hugo.yaml`
- About page: `content/about.md`
- Projects: one Markdown file per project in `content/projects/`
- CV / images: put files in `static/` (e.g. `static/cv.pdf` → `/cv.pdf`)

## Preview locally (optional)
```bash
git clone --depth 1 https://github.com/adityatelange/hugo-PaperMod themes/PaperMod
hugo server
```
Then open http://localhost:1313
