## What it is

A **habit-tracking web app** with a **recommendation** component, built for the Assistance Systems course at TH Deggendorf.

---

## Architecture

- **Web app:** React front end with a Node.js and MongoDB back end
- **Recommendation service:** a separate **FastAPI** service
- **Testing:** **PyTest** unit and integration tests for the service
- **Docker** for reproducible builds, tests and runs

---

## Stack

`React` · `Node.js` · `MongoDB` · `FastAPI` · `PyTest` · `Docker`
